# Adex Main | Frontend Developer Portfolio

Professional portfolio for Adex Main, a frontend developer focused on responsive web interfaces, JavaScript, and React.

## Projects

- `portfolio/` - professional portfolio site
- `ledgerly-react/` - React implementation of the Ledgerly fintech experience
- `ledgerly-js/` - original HTML, CSS, and JavaScript implementation

## Preview the portfolio

Open `portfolio/index.html` in a browser.

Add the portrait image as `portfolio/assets/profile.jpg` to replace the built-in corporate portrait placeholder.

## Run Ledgerly React

```bash
cd ledgerly-react
npm install
npm start
```

## Checks

```bash
cd ledgerly-react
npm test -- --watchAll=false
npm run build
```
